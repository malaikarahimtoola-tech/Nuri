# Nuri + Chronically integration

Open `index.html` to start the Nuri web app. The pink announcement link at the top of the public landing page opens `chronically.html`.

Included pages:

- `index.html` — existing Nuri web app with the Chronically entry point
- `chronically.html` — Chronically landing page
- `why-are-we-building-a-recipe-app.html` — Edition #1 article
- `chronically.css` — Chronically landing page and article styles

Keep the existing `assets` folder beside these files. The Chronically pages expect:

- `assets/NURI_LOGO.png`
- `assets/chronically-hero.jpg`
- `assets/article-1-nuri.jpg`
- `assets/article-2-nuri.jpg`
- `assets/article-nuri.jpg`
